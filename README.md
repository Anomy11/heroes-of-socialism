# Heroes of Socialism

25 hand-inked comrades, one party trick each. Every line is drawn in code — one self-contained HTML file, no images, no libraries, all sound synthesized.

**Live:** https://heroes-of-socialism.pages.dev (Cloudflare Pages, deploy with `./deploy.sh`)

- Click / tap a head for its trick, drag to turn it
- `A` May Day parade · `R` surprise me · `N` reshuffle · `G` gossip · `W` wave · `S` sneeze · `F` fly · `space` group photo · `M` sound
- Deep link to a trick: `?c=marx`, `?c=gagarin`, `?c=khrushchev` …
